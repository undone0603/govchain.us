# GovChain.us

Blockchain-verified government procurement and supply chain authentication.

Live at: https://govchain.us

## About

GovChain delivers tamper-proof product authentication and immutable audit trails for federal, state, and DoD procurement workflows. Built on AuthiChain infrastructure.

## GitHub Pages

This repository is deployed via GitHub Pages. The `main` branch serves `index.html` as the root.
